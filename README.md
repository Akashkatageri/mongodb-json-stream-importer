MongoDB JSON Stream ImporterOverviewThe json_stream_importer.py script is a high-performance Python utility designed to efficiently stream extremely large JSON files into a MongoDB database.It leverages the ijson library to avoid loading the entire file into memory (preventing memory exhaustion) and utilizes MongoDB's optimized insert_many bulk operations for rapid data ingestion. The script is resilient, supporting automatic resume functionality, dynamic JSON format detection, and robust error handling for large-scale, production-level imports.FeaturesMemory Efficient: Uses ijson to stream data, supporting files larger than available RAM.Bulk Insertion: Employs pymongo's bulk writes for maximum insertion speed.Resume Capability: Start the import from a specific document count, crucial for interrupted jobs.Unordered Writes: Uses ordered=False to maximize throughput and ensure the import continues even if individual documents fail (e.g., due to schema validation or other minor errors).Dynamic Prefix Detection: Automatically detects if the JSON is a top-level array ([...]) or nested ({"data": [...]}).Connection Resilience: Configurable, extended timeouts for connection and socket operations.PrerequisitesBefore running the script, ensure you have the following installed:Python 3.6+A running MongoDB instance (local or remote).Required Python packages:pip install ijson pymongo

Resuming an ImportIf the script terminates (e.g., network loss, system crash), check the last line printed to the console:Streaming: Processed 10,500,000 | Inserted: 10,480,000 (in this run) | Rate: 2,500.1 docs/sec

To resume, set RESUME_COUNT to the last Processed number (e.g., 10500000) and restart the script. The script will quickly skip those documents and continue the import from the next one.How JSON Prefix Detection WorksThe script attempts to determine the path to your array of documents:| JSON Structure | Detected Prefix || [{"key": "value"}, {"key": "value"}] | item || {"data": [{"key": "value"}, ...], "meta": {}} | data.item || {"items": [{"key": "value"}, ...], "version": 1} | items.item (Defaulting to data.item might require manual adjustment for less common root keys) |
